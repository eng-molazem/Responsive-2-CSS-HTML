## 🇬🇧 English

### Overview

A second front-end practice project focused on building a responsive web page layout using pure HTML and CSS (media queries, flexible layouts), deployed with GitHub Pages. A companion exercise to [Responsive-1-CSS-HTML](https://github.com/eng-molazem/Responsive-1-CSS-HTML).

### Tech Stack

HTML, CSS (no frameworks).

### Getting Started

Open `index.html` directly in your browser, or serve the folder with any static file server.
